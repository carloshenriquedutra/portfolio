# Contrato de apresentação

- Empresa e um h1 abrem o detalhe.
- Dois cards h2: problema e contribuição.
- Uma seção de ferramentas.
- Decisões com h3 e cinco parágrafos rotulados, ou análise municipal para COPAPA.
- Links finais para projetos e contato preservam a integração de idioma existente.
- O HTML inicial inglês coincide com o renderer; o breadcrumb mantém sua função de navegação.
